"Borrowed Hands": a program that writes one short poem about agency to
`/output/entry.txt`. Someone asks the speaker to sign for them with a hand still
warm from their own; years later the same hand signs smaller, and the poem never
says whether that is gratitude or distance.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

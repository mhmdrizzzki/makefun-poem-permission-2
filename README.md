A program that writes one short poem to `/output/entry.txt`: a poem about agency,
the power to ask and to be given. "Borrowed Hands" is about a speaker who is asked
to sign someone else's name, writes it better than its owner does, and years later
finds that own signature shrunken against the standard the borrower set.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
